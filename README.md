# MONOCHROME — музыка без цвета

Чёрно-белый музыкальный плеер: поиск по реальным каталогам, полные треки через
SoundCloud, «Моя волна» и плейлисты по настроению. Русский интерфейс, строгая
монохромная тема. Веб-PWA + Android APK.

## Скачать

- **Android APK** — https://github.com/Chr0mat1x/monochrome-music/releases/latest/download/MONOCHROME.apk
  Скачай на телефон и открой файл (разреши установку из неизвестных источников).
- **Исходники** — этот репозиторий.

APK самодостаточен: у него внутри Java-мост к SoundCloud, поэтому он ищет и
играет полные треки без отдельного сервера. Интернету нужен только доступ к
SoundCloud.

## Локальный запуск

```bash
npm install
npm run dev        # сайт на :12000 + аудио-прокси на :8787
```

`npm run dev` сам поднимает `yt-dlp` и прокси, чтобы полные треки работали из
коробки. Отдельный сервер нужен только веб-версии (поиск Deezer/iTunes/Audius,
резолв, авторизация) — APK его не использует.

## Постоянный адрес (хостинг)

Веб-версии нужен сервер: API SoundCloud не отдаёт CORS-заголовки, а его CDN
отказывает анонимным запросам с датацентров, поэтому браузер не может ходить
туда напрямую. Сервер проксирует каталог и склеивает HLS в MP4.

В репозитории уже лежит `Dockerfile` (Node 22, без `yt-dlp` и `ffmpeg` —
звуковой путь SoundCloud это чистый HTTP) и конфиги для хостингов:

- **Amvera** (`amvera.yml`) — российский PaaS, не блокируется в РФ, оплата
  российской картой. Создай приложение типа «Docker», привяжи этот
  репозиторий — дальше деплой идёт `git push`.
- **Render** (`render.yaml`) — бесплатный тариф, но `*.onrender.com`
  нестабилен из России и сервис засыпает через 15 минут простоя.
- **Railway** (`railway.json`) — бесплатного тарифа больше нет.

Важно: **Cloudflare (workers.dev / pages.dev) в России заблокирован**, как и
многое на IP Cloudflare, поэтому эти варианты не подходят. GitHub Pages тоже
не подходит — там нельзя запустить сервер, а без него нет звука.

Проверить образ локально:

```bash
docker build -t monochrome .
docker run -p 8787:8787 monochrome   # http://localhost:8787
```

## Сборка APK

```bash
bash scripts/bootstrap.sh   # ставит JDK и Android SDK (переживает перезапуск контейнера)
npm run build:apk           # -> downloads/MONOCHROME.apk
```

`bootstrap.sh` нужно запускать после каждого перезапуска контейнера: JDK,
Android SDK и `yt-dlp` живут вне репозитория и стираются вместе с ним.

## Возможности

- Поиск треков, артистов и альбомов; обложки и метаданные.
- Полные треки: SoundCloud (основной), Deezer/iTunes/Audius (запасные); если
  полной версии нет — играет 30-секундное превью, в UI это помечено бейджем
  `ПРЕВЬЮ 30С` против `ПОЛНЫЙ ТРЕК`.
- «Моя волна»: бесконечный поток, который учится на лайках и истории.
- Генератор плейлиста по настроению: опиши состояние словами («мрачный техно
  для ночной поездки») — получишь плейлист из реальных треков.
- Медиатека, лайки, установка как PWA.

## Структура

```
src/          фронтенд (React + Vite, монохромная тема)
server/       аудио-прокси и каталог-прокси для веб-версии
android/      Android-оболочка + SoundCloudBridge.java (без сервера)
public/       PWA: манифест, service worker, иконки
scripts/      bootstrap, dev-оркестрация, сборка APK
Dockerfile    образ для постоянного хостинга (сайт + /api в одном процессе)
```

## Хостинг: почему сервер обязателен

SoundCloud не отдаёт `Access-Control-Allow-Origin` и не поддерживает JSONP,
поэтому браузер не может обратиться к `api-v2.soundcloud.com` напрямую. Плюс
CDN воспроизведения отказывает анонимным запросам с датацентров. Отсюда:
статический хостинг (GitHub Pages, Netlify, Cloudflare Pages) для этого сайта
не работает — нужен процесс, который проксирует и каталог, и звук.

`Dockerfile` собирает такой образ: `npm ci && vite build`, затем рантайм-стадия
отдаёт `dist/` и `/api` из одного Node-процесса. `yt-dlp` и `ffmpeg` в образ не
входят — путь SoundCloud (`api-v2` + склейка HLS) это обычные HTTP-запросы.

Готовые конфиги: `amvera.yml` (российский хостинг, доступен без VPN),
`render.yaml`, `railway.json`. Сервер слушает `PORT`, если он задан хостингом,
иначе `MONO_SERVER_PORT`, иначе `8787`.
