# MONOCHROME — музыка без цвета

Чёрно-белый музыкальный плеер: поиск по реальным каталогам, полные треки через
SoundCloud, «Моя волна» и плейлисты по настроению. Русский интерфейс, строгая
монохромная тема. Веб-PWA + Android APK.

## Скачать

- **Android APK** — https://github.com/Chr0mat1x/monochrome-music/releases/latest/download/MONOCHROME.apk
  Скачай на телефон и открой файл (разреши установку из неизвестных источников).
- **Исходники** — этот репозиторий.

APK самодостаточен: у него внутри Java-мост к SoundCloud, поэтому он ищет и
играет полные треки без отдельного сервера. Интернету нужен только доступ к
SoundCloud.

## Локальный запуск

```bash
npm install
npm run dev        # сайт на :12000 + аудио-прокси на :8787
```

`npm run dev` сам поднимает `yt-dlp` и прокси, чтобы полные треки работали из
коробки. Отдельный сервер нужен только веб-версии (поиск Deezer/iTunes/Audius,
резолв, авторизация) — APK его не использует.

## Сборка APK

```bash
bash scripts/bootstrap.sh   # ставит JDK и Android SDK (переживает перезапуск контейнера)
npm run build:apk           # -> downloads/MONOCHROME.apk
```

`bootstrap.sh` нужно запускать после каждого перезапуска контейнера: JDK,
Android SDK и `yt-dlp` живут вне репозитория и стираются вместе с ним.

## Возможности

- Поиск треков, артистов и альбомов; обложки и метаданные.
- Полные треки: SoundCloud (основной), Deezer/iTunes/Audius (запасные); если
  полной версии нет — играет 30-секундное превью, в UI это помечено бейджем
  `ПРЕВЬЮ 30С` против `ПОЛНЫЙ ТРЕК`.
- «Моя волна»: бесконечный поток, который учится на лайках и истории.
- Генератор плейлиста по настроению: опиши состояние словами («мрачный техно
  для ночной поездки») — получишь плейлист из реальных треков.
- Медиатека, лайки, установка как PWA.

## Структура

```
src/          фронтенд (React + Vite, монохромная тема)
server/       аудио-прокси и каталог-прокси для веб-версии
android/      Android-оболочка + SoundCloudBridge.java (без сервера)
public/       PWA: манифест, service worker, иконки
scripts/      bootstrap, dev-оркестрация, сборка APK
```
